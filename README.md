# shija-pmjay

Shija Dialysis patient records demo. The site opens without a login.

## Run locally

1. Install Node.js 20 or newer.
2. Run `npm install`.
3. Run `npm start` and open `http://localhost:3000`.

## Deploy on Render

1. Push this repository, including `render.yaml`, to GitHub.
2. In Render, create a new Blueprint and connect this repository.
3. Open the service's `onrender.com` URL. No login secrets are required.

The site is public to anyone with its URL. Patient records are stored in browser local storage, not on the server. This is a demo and is not suitable for real patient or health information.
